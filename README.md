# Aaron Myers · BaldDBA

Oracle DBA for almost **20 years**. I like **Python**, and most of the tools here were built for me — to automate real work, or to chase ideas in my homelab. The ones that earn their keep get shared.

Most of what I build starts as a **CLI** or **TUI**. I’m a big fan of **FastAPI** and web services on the backend. Frontends are a different story: building web UIs isn’t my favorite work, so I’ve been putting interfaces on some tools with AI — mostly for fun, and as a hands-on way to learn how far AI can take that part of the stack.

## Experience & focus

- Nearly two decades as an Oracle DBA — operations, security, compliance, and the glue between systems
- Prefer Python for automation: scripts that grow into CLIs, TUIs, and small services when they need to
- Tools scratch my own itch first — day-job workflows and homelab experiments — then get cleaned up for others
- CLI/TUI by default; FastAPI when an API fits; web UIs when I want to play with AI-assisted frontends
