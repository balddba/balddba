# Aaron Myers · BaldDBA

Oracle DBA for almost **20 years**. I like **Python**, and most of the tools here were built for me — to automate real work, or to chase ideas in my homelab. The ones that earn their keep get shared.

Most projects start as a **CLI** or **TUI**, with **FastAPI** behind the web tools. I’ve been experimenting with AI-assisted frontends to give more of them a usable interface.
